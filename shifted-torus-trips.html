One trip, then an angular shift

One continuous ribbon. Each trip runs once lengthwise around the torus; the next trip is shifted around the tube by Δ.

u(q) = 2πq
v(q) = v₀ + Δq
0 ≤ q ≤ number of trips
q → q+1: one trip, tube shift Δ
