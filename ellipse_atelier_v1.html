Ellipse Atelier / Ten studies

One sinusoidal ellipse, ten new visual languages. Explore evolving ribbons, intricate interference, radial symmetry and sculptural depth. Everything runs locally, without libraries or network access.

Construction notes

The starting construction is x = (a + r) cos θ, y = (b + r) sin θ, with r = A sin(mθ + t) sin(nθ). These studies alter its layering, symmetry, harmonic content, or projection. Frequencies are integers so the base curves close over 0 ≤ θ ≤ 2π. Color is evaluated along each curve rather than applied as a single final stroke.

Controls: amplitude and aspect are relative to the fitted scene; layers controls the number of contours or symmetry copies. Complexity increases both the highest frequencies and the sampling density. PNG exports the current canvas (not the interface). Animation speed is elapsed-time based. Reduced-motion preferences start the scene paused.
