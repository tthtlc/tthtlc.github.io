Vector-modified sine waves

Vector slots 4 and 5 provide one shared displacement. Every generated sine-wave endpoint is translated by that displacement before being stored and drawn.

Random vector · 5-slot buffer

Five translated sine waves · 40 slots each

Slots are numbered 1–5, corresponding to indices 0–4. Slot coordinates are path endpoints. Because these are physical circular-buffer slots, slot 5 is not always newer than slot 4. Gain 1 implements the requested offset exactly; higher gain exaggerates it. Changes affect new segments only. The vector and wave plots use upward-positive y coordinates.
