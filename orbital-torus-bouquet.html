Orbital torus bouquet

Geometry

Several slender tori share one centre like orbital paths. Ring k takes its plane normal from a golden-angle azimuth and a tilted polar angle:

θ_k = 2.39996 k + irregularity · h2
φ_k = 25° + tiltRange · h3
n_k = (sin φ_k cos θ_k, sin φ_k sin θ_k, cos φ_k)

Here h1 … h4 are deterministic hashes fract(sin(n · 127.1) · 43758.5), so the arrangement is stable but never perfectly regular. Because 2.39996 is the golden angle, consecutive azimuths never repeat — the bouquet stays deliberately uneven rather than mechanical.

Each centreline is built in the plane perpendicular to its normal from an orthonormal basis, then swept with a tube of radius r; ring radii R_k = R(0.8 + 0.4 h1) vary slightly and every ring is pushed along its own normal by sep · R so the centre breathes.

Colour stays in one family: ring k's hue is base + spread · h4, so the palette is varied but bounded — never a rainbow.
